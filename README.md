# SkillBridge - Smart Freelancing Platform

## Project Description

SkillBridge is a frontend-based freelancing platform that helps
freelancers discover suitable job opportunities based on their skills.

The platform calculates a skill-match percentage between the
freelancer's skills and the skills required by each job.

## Features

- Freelancer profile creation
- Job search
- Category filtering
- Skill-based job matching
- Match percentage calculation
- Save and unsave jobs
- Apply-interest tracking
- Post new freelance jobs
- Browser data storage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage
- sessionStorage

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Open index.html.
5. Right-click and select Open with Live Server.

## Project Type

Frontend Mini Project

## Note

This project is a frontend prototype.
It does not include a backend server,
database or real authentication.
